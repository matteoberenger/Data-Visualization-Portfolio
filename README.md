# Data-Visualization-Portfolio
Portfolio of projects from my Data Visualization course. This repository showcases my work from MIS 561: Data Visualization at the University of Arizona. Throughout the course, I will build and refine projects using Excel, Tableau, Power BI, Adobe Express, DataCamp, and generative AI tools. The portfolio will include guided exercises, applied business visualizations, dashboards, data storytelling projects, and a final visualization project. My goal is to strengthen both the technical and design sides of data visualization by creating clear, effective, and professional visuals that support business decision-making. This GitHub will serve as a growing portfolio of my progress, skills, and completed coursework throughout the semester and professional development

Introduction to Power BI: Completed on 9/23/2026. [https://public.tableau.com/views/PowerBITraining_17901918243800/PowerBIStory?:language=en-US&publish=yes&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link]
One thing Power BI does automatically is connect and summarize data across tables without requiring as much manual setup as I used in Excel and Tableau. In Flex 3 and Flex 4, I had to create calculations, joins, and summaries by hand before building the visuals. Next time, I would choose Power BI for this part because it would make the data preparation faster and reduce the amount of repetitive work. I would still use Tableau when I want more control over the final visual design.
